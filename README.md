# 🌾 Projeto Agrinho 2026 - Categoria Desenvolvimento Front-End

## 📝 Sobre o Projeto
Este site foi desenvolvido como projeto para o **Concurso Agrinho 2026**, promovido pelo Sistema FAEP/SENAR-PR em parceria com a SEED-PR. 

O objetivo da página é explorar e conscientizar sobre o tema oficial deste ano: 
> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

A página apresenta como a tecnologia e as boas práticas agrícolas (como o uso de drones, energias renováveis e o plantio direto) ajudam o campo a produzir alimentos de forma eficiente enquanto preservam os recursos naturais do planeta.

---

## 🚀 Tecnologias Utilizadas
O projeto foi construído do zero utilizando as tecnologias de Front-End aprendidas durante o curso na plataforma **Alura**:
* **HTML5:** Para a estruturação semântica do conteúdo.
* **CSS3:** Para a estilização, design responsivo, uso de *Flexbox* e técnicas de *Box Model*.
