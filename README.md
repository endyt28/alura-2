# 🌾 Projeto Agrinho 2026 - Categoria Desenvolvimento Front-End

## 📝 Sobre o Projeto
Este site foi desenvolvido como projeto para o **Concurso Agrinho 2026**, promovido pelo Sistema FAEP/SENAR-PR em parceria com a SEED-PR. 

O objetivo da página é explorar e conscientizar sobre o tema oficial deste ano: 
> **“Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”**

A página apresenta de forma visual e interativa como a tecnologia e as boas práticas agrícolas (como o uso de drones, energias renováveis e o plantio direto) ajudam o campo a produzir alimentos de forma eficiente enquanto preservam os recursos naturais do planeta.

---

## 🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as tecnologias de desenvolvimento web aprendidas e aprimoradas durante o curso na plataforma **Alura**:
* **HTML5:** Estruturação semântica do conteúdo (uso de tags como `<header>`, `<main>`, `<section>`, `<footer>`).
* **CSS3:** Estilização completa, layouts modernos e flexíveis com *Flexbox*, controle de espaçamentos com *Box Model* e efeitos visuais de transição (`:hover`).
* **JavaScript (JS):** Lógica de programação para criar a calculadora dinâmica do site.
* **Git & GitHub:** Para controle de versão e hospedagem do código na nuvem.

---

## ✨ Funcionalidades do Site
* **Design Responsivo:** A página se adapta e pode ser lida perfeitamente em computadores, tablets e celulares.
* **Navegação Suave:** Menu superior com links âncora que levam o usuário direto para a seção desejada sem recarregar a página.
* **Cards Interativos:** Seção de tecnologias agrícolas com efeito visual de "flutuar" ao passar o mouse.
* **Simulador de Impacto Tecnológico:** Uma ferramenta interativa onde o usuário digita o tamanho de uma plantação em hectares e descobre a estimativa de litros de água economizados com o uso de irrigação inteligente.
* **Identidade Visual Temática:** Cores escolhidas a dedo (tons de verde, terra e branco) para transmitir a união entre natureza, sustentabilidade e tecnologia.

## 🛠️ Aprendizados da Alura Aplicados
Durante o desenvolvimento desta página através do curso, eu pude dominar conceitos fundamentais como:
1. **Semântica HTML:** Entender que o código precisa ser organizado para que navegadores e leitores de tela compreendam a estrutura do site.
2. **Propriedades do CSS:** Como utilizar `padding`, `margin` e `border` para dar o espaçamento correto e elegante aos elementos.
3. **Manipulação do DOM com JavaScript:** Capturar dados digitados pelo usuário, fazer cálculos matemáticos e exibir o resultado diretamente na tela de forma dinâmica.
